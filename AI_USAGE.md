# AI Usage

## AI Tools Used

- ChatGPT (OpenAI)
- Grok AI (xAI)
- GitHub Copilot (used occasionally for code suggestions and auto-completion)

## Purpose of AI Usage

AI tools were used only as development assistants to improve productivity and code quality. 
The assistance included:

- Planning the React project structure and folder organization.
- Improving reusable component architecture.
- Suggesting responsive UI layouts and CSS improvements.
- Debugging React and Express.js errors.
- Reviewing code quality and identifying mistakes.
- Providing guidance for implementing a basic Express backend with mock APIs.
- Suggesting improvements for validation, routing, and user interface consistency.
- Helping improve documentation such as the README and project explanation.

## Verification

Every AI-generated suggestion was manually reviewed, tested, and modified where necessary before being included in the project.

The final implementation, testing, debugging, and integration were completed manually to ensure the application worked correctly.
